# نظام إدارة شؤون الموظفين — الهلال الأحمر الفلسطيني

مرحلة شاشة الموظفين: إعداد حساب المدير عند أول دخول، سجل قابل للبحث والتصفية، واستيراد ملف Excel مرة واحدة إلى PostgreSQL.

## مكونات التطبيق

- `web`: تطبيق FastAPI داخل حاوية Docker، يستمع على المنفذ الداخلي `8000`.
- `db`: PostgreSQL 17 داخل شبكة Compose مع تخزين دائم في `hr_postgres_data`، ومن دون نشر قاعدة البيانات على الإنترنت.
- `public.employees`: جدول بيانات الموظفين من migration رقم 001.
- `public.employee_import_control`: يسجل عملية الاستيراد الوحيدة من migration رقم 002.
- ملف الموظف يدعم العرض والتعديل والتجميد وإعادة التفعيل؛ التجميد محفوظ في قاعدة البيانات ويمنع التعديل من واجهة التطبيق ومن الخادم.
- `public.admin_account`: حساب مدير واحد، يُنشأ من شاشة الإعداد عند أول دخول، من migration رقم 003.
- كلمات مرور المدير تُخزّن بتجزئة آمنة في قاعدة البيانات. لا توجد كلمة مرور إدارية في ملفات المشروع أو متغيرات البيئة.
- الملف يُقرأ مباشرة في الذاكرة ولا يُخزن على القرص أو في GitHub. الاستيراد داخل معاملة واحدة: إما تُحفظ كل الصفوف أو لا يُحفظ أي صف.

## إعداد Coolify

1. استخدم المستودع `WalaaPRCS/HR` والفرع `main` واستراتيجية Docker Compose مع الملف `docker-compose.yaml` من جذر المستودع.
2. أضف المتغيرات التالية في إعدادات المورد. لا ترسل كلمة مرور قاعدة البيانات أو مفتاح الجلسات في GitHub أو المحادثة:
   - `POSTGRES_PASSWORD`: كلمة مرور قوية لقاعدة البيانات.
   - `SESSION_SECRET`: سلسلة عشوائية سرية بطول 32 حرفاً على الأقل.
   - اختياري: `POSTGRES_DB` الافتراضي `prcs_hr`، و`POSTGRES_USER` الافتراضي `prcs_hr_app`.
   - `COOKIE_SECURE` اختياري، افتراضيه `true` عند استخدام HTTPS.
3. اربط الدومين `prcs.hr.infinite.ps` بخدمة `web` واستخدم المنفذ الداخلي `8000` كـ Container Port/Target Port في إعداد الدومين أو التوجيه في Coolify.
4. افتح الدومين عبر HTTPS. Coolify يستقبل اتصال المستخدم على الدومين و443، ثم يمرر الطلب داخل الشبكة إلى خدمة التطبيق على 8000. لا يحتاج المستخدم لإضافة `:8000` إلى رابط الموقع ولا يلزم فتح هذا المنفذ للعامة.
5. عند أول زيارة ستظهر شاشة إنشاء حساب المدير. أدخل اسم المستخدم وكلمة المرور وأكدها. يُسمح بإنشاء حساب مدير واحد؛ وبعدها ستظهر شاشة تسجيل الدخول.
6. من «الموظفون» اختر ملف `.xlsx` واضغط تأكيد الاستيراد. يفضل أن تحتوي الورقة على الأعمدة العربية الأصلية وأن تسمى «الموظفون». الحد الأعلى لحجم الرفع 16 ميجابايت.

## قاعدة البيانات والترقيات

يُطبّق التطبيق ملفات migrations عند بدء التشغيل. كما يشغل PostgreSQL ملفات التهيئة في `/docker-entrypoint-initdb.d` عند إنشاء volume جديد لأول مرة. لا تحذف volume قاعدة البيانات إذا كانت تحوي بيانات تريد الاحتفاظ بها.

## الملفات

- `main.py`: إعداد المدير وتسجيل الدخول وواجهات API وقراءة ملف Excel والتحقق والاستيراد.
- `database/migrations/`: إنشاء الجداول والفهارس.
- `public/`: واجهات الدخول ولوحة المعلومات وشاشة الموظفين.
- `Dockerfile` و`docker-compose.yaml`: بناء وتشغيل التطبيق وقاعدة البيانات.

ملف Excel وسجلات الموظفين غير موجودة في المستودع.
