# نظام إدارة شؤون الموظفين — الهلال الأحمر الفلسطيني

واجهة أولية عربية RTL مع إعداد تشغيل عبر Docker Compose.

## الخدمات

- `web`: يخدم `index.html` عبر Nginx على المنفذ الداخلي `80`، مع فحص صحة على `/healthz`. اربط الدومين بخدمة `web` في Coolify.
- `db`: PostgreSQL 17 داخل شبكة Compose فقط، مع volume دائم باسم `hr_postgres_data`. لا يوجد نشر لمنفذ قاعدة البيانات على الإنترنت.
- عند تهيئة volume جديد لأول مرة، ينفذ PostgreSQL مخطط `database/migrations/001_create_employees.sql` لإنشاء جدول `public.employees`.

## إعداد Coolify

1. استخدم المستودع `WalaaPRCS/HR` والفرع `main`.
2. اختر استراتيجية Compose وحدد الملف `docker-compose.yaml` من جذر المستودع.
3. أضف متغيرات البيئة التالية في إعدادات المورد قبل أول نشر:
   - `POSTGRES_PASSWORD`: كلمة مرور قوية، تُحفظ في Coolify فقط ولا تُضاف إلى GitHub.
   - `POSTGRES_DB`: اختياري؛ الافتراضي `prcs_hr`.
   - `POSTGRES_USER`: اختياري؛ الافتراضي `prcs_hr_app`.
4. بعد تحميل ملف Compose، أضف الدومين `prcs.hr.infinite.ps` إلى خدمة `web` من قسم Domains في المورد، ثم نفّذ النشر.
5. تأكد من إعداد DNS للدومين ليوجه إلى عنوان الخادم، ومن تفعيل HTTPS في Coolify.

> الواجهة الحالية للعرض فقط ولا تتصل بقاعدة البيانات بعد. يلزم بناء الخادم الخلفي وربطه قبل استخدام النظام تشغيليًا. مخطط الجدول يطبق تلقائيًا فقط عندما تكون قاعدة البيانات فارغة لأول مرة. لا تحذف volume لإعادة التهيئة إذا كانت هناك بيانات تريد الاحتفاظ بها. لا يحتوي المستودع على ملف الموظفين.
