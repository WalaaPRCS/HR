# نظام إدارة شؤون الموظفين — الهلال الأحمر الفلسطيني

مرحلة شاشة الموظفين: تسجيل دخول، سجل قابل للبحث والتصفية، واستيراد ملف Excel مرة واحدة إلى PostgreSQL.

## مكونات التطبيق

- `web`: تطبيق FastAPI على المنفذ الداخلي `8000`.
- `db`: PostgreSQL 17 داخل شبكة Compose مع تخزين دائم في `hr_postgres_data`، ومن دون نشر قاعدة البيانات على الإنترنت.
- `public.employees`: جدول بيانات الموظفين من migration رقم 001.
- `public.employee_import_control`: يسجل عملية الاستيراد الوحيدة من migration رقم 002.
- يتصل التطبيق بقاعدة البيانات ويطبق ملفات migrations عند بدء التشغيل.
- شاشة الموظفين محمية بتسجيل الدخول. الملف يُقرأ مباشرة في الذاكرة ولا يُخزن على القرص أو في GitHub. الاستيراد داخل معاملة واحدة: إما تُحفظ كل الصفوف أو لا يُحفظ أي صف.

## إعداد Coolify

1. استخدم المستودع `WalaaPRCS/HR` والفرع `main` واستراتيجية Docker Compose مع الملف `docker-compose.yaml` من جذر المستودع.
2. أضف متغيرات البيئة في إعدادات المورد. لا ترسل كلمات المرور في GitHub أو المحادثة:
   - `POSTGRES_PASSWORD`: كلمة مرور قوية لقاعدة البيانات.
   - `HR_ADMIN_USERNAME`: اسم مستخدم مدير النظام.
   - `HR_ADMIN_PASSWORD`: كلمة مرور مدير النظام.
   - `SESSION_SECRET`: سلسلة عشوائية سرية بطول 32 حرفاً على الأقل.
   - اختياري: `POSTGRES_DB` الافتراضي `prcs_hr`، و`POSTGRES_USER` الافتراضي `prcs_hr_app`.
   - اختياري: `COOKIE_SECURE` الافتراضي `true` عند استخدام HTTPS.
3. بعد تحميل Compose، اربط الدومين `prcs.hr.infinite.ps` بخدمة `web` على المنفذ الداخلي `8000`، ثم انشر المورد وفعّل HTTPS.
4. افتح الدومين وسجل الدخول، ثم من «الموظفون» اختر ملف `.xlsx` واضغط تأكيد الاستيراد. يجب أن تحتوي الورقة على الأعمدة العربية الأصلية، وتُفضل ورقة باسم «الموظفون». الحد الأعلى لحجم الرفع 16 ميجابايت.
5. لا تعِد تهيئة volume قاعدة البيانات الموجودة إذا كانت تحوي بيانات تريد الاحتفاظ بها. ملفات التهيئة داخل `/docker-entrypoint-initdb.d` تُشغّل عند أول إنشاء للـ volume؛ أما التطبيق فيراجع migrations عند كل بدء تشغيل.

## الملفات

- `main.py`: تسجيل الدخول وواجهات API والقراءة والتحقق والاستيراد.
- `database/migrations/`: إنشاء الجداول والفهارس.
- `public/`: واجهات تسجيل الدخول واللوحة وشاشة الموظفين.
- `Dockerfile` و`docker-compose.yaml`: بناء وتشغيل التطبيق وقاعدة البيانات.

ملف Excel وسجلات الموظفين غير موجودة في المستودع.
